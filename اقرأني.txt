ملفات موقع BRO
================
ارفع محتويات هذا المجلد إلى جذر مستودع GitHub، وليس المجلد الخارجي نفسه.

الملفات:
- index.html: الصفحة الرئيسية
- education.html: صفحة التعليم
- religion.html: صفحة الدين والمعرفة
- places.html: صفحة الأماكن والخدمات
- chat.html: صفحة اسأل بوبوت
- css/style.css: التصميم المشترك
- js/script.js: تفاعل القائمة والنماذج والمحادثة التجريبية

مهم:
هذه نسخة واجهة أمامية. المحادثة ليست ذكاءً اصطناعياً حقيقياً، ولا يوجد بحث تلقائي داخل BRO حتى الآن. نموذج الأماكن يفتح بحث جوجل خارج الموقع. لا تضع مفاتيح API داخل ملفات HTML أو JavaScript العامة.
